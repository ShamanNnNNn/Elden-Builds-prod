Elden Builds

Fullstack веб - приложение для создания, публикации и модерации билдов и гайдов по Elden Ring
 О проекте

Elden Builds - это платформа, где игроки могут делиться своими билдами, писать подробные гайды, оценивать чужие работы и общаться через комментарии.
Приложение включает систему модерации для контроля качества контента.
Возможности
 Пользователи

    Регистрация и авторизация пользователей

    JWT + Refresh Token аутентификация

    Ролевая модель (USER, ADMIN)

 Билды

     Создание и редактирование билдов

     Детальное описание экипировки (оружие, броня, талисманы)

     Система шкал урона (Strength, Dexterity, Intelligence, Faith, Arcane)

     Фильтрация по типу урона и классу оружия

     Сортировка по лайкам, дате, названию

 Модерация

    Административная панель

    Одобрение/отклонение новых билдов

    Управление пользовательским контентом

 Взаимодействие

    Система лайков для билдов

    Комментарии под билдами

    Счётчики просмотров и популярности

 Медиа

    Загрузка изображений (превью билдов, скриншоты)

    Встроенный редактор гайдов с поддержкой текста и изображений
